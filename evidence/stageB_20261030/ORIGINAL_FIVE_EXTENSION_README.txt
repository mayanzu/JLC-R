This extension covers 2,664 cases across six study groups in the 24-seed evaluation, including the 2,280 Stage B cases and 384 JLC-Base/JLC-Core control runs. It provides run-level and per-source records, the five-method Holm-8 primary comparison, and the 64-test condition-specific family.
Run `python -B verify_compact.py`, `python -B verify_original_five.py`, and `python -B verify_packet_trace.py` from this directory to verify all summaries without starting simulations. Recompute winter diagnostics with `python -B audit_winter_diagnostics.py --stage . --output NEW_DIRECTORY`.
